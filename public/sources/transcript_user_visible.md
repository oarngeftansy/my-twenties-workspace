我觉得这里面最值得抓住的核心，其实是：

> **“模拟一个女生下班之后，如何一点点把自己的人生过成自己想要的样子。”**

这样它就不会变成《模拟人生》那种什么都做的大型 life sim，而是有非常明确的切口：**20–30 岁女性的工作、独居、消费、关系与自我成长。**

而且你提到的“上班后房间会变脏，周末有比较解压的打扫玩法”这个点，我反而觉得特别好。因为它把**职场压力 → 生活状态 → 玩家行为 → 情绪反馈**连起来了。

比如：

**周一加班 → 精力下降 → 外卖盒堆积 → 衣服没收 → 周末终于有时间 → 整理房间小游戏 → 房间恢复 → 心情上涨 → 换床单/点香薰/重新布置 → 周日晚上进入新的状态。**

这就比单纯的“装修系统”有生命力。

同理，其他系统最好也这么设计。比如创业不只是点“创业”，而是：

**工作不爽 → 产生转行/创业念头 → 下班做副业 → 周末参加市集 → 认识新的人 → 收入逐渐变化 → 可以辞职 → 生活节奏发生变化 → 新事件池开启。**

这样**职业、生活、恋爱、房间、消费不是五个独立小游戏，而是在互相影响。**

你这个项目我甚至觉得可以暂时用一个很清晰的概念来框：

### 「下班以后」Life Sim

白天是社会身份，晚上才是玩家真正可以控制的人生。

核心循环可以压成：

**工作 / 学习 → 获得金钱与压力 → 下班自由时间 → 选择社交 / 恋爱 / 整理 / 购物 / 副业 / 休息 → 改变属性与关系 → 触发新机会 → 人生路线逐渐分化。**

然后你说的 GAP 模拟器、不同男主、时尚、装修、心理测试，都可以自然挂在这个循环下面。

还有一个我认为很重要的方向：**不要一开始就做“情感系统”“时尚系统”“创业系统”这种大系统。** 这个 idea 最大的风险就是越想越像《模拟人生》+《恋与深空》+《动物森友会》+ 职场模拟器，最后根本做不完。

第一版 vertical slice，我建议只做：

**一间出租屋 + 一份工作 + 7 天时间 + 3 个可去地点 + 2 个可认识角色 + 周末整理房间 + 一次职业选择。**

先证明最重要的一件事：

> **“上班 → 下班 → 安排自己的生活 → 房间和关系发生变化 → 我开始期待明天下班”这个循环到底好不好玩。**

只要这个循环成立，后面的恋爱、创业、时尚、装修都可以不断往里面加。

而且这和你之前做的偏机制型游戏不太一样，这个方向真正有潜力的地方是**情绪价值 + 女性生活观察 + 高频短反馈**。后面甚至可以专门设计一套“生活事件生成器”：同事突然甩锅、工资到账、喜欢的衣服打折、朋友临时约饭、男主发消息、下雨不想出门、周末房间乱得不想收拾……这些小事件才会决定这个游戏有没有“活人感”。

这个 idea 值得继续往下拆。下一步最应该做的不是继续想更多系统，而是把**核心体验、一天循环、7 天 vertical slice 和长期人生分支**四层先定下来。

# 《项目代号：下班以后》初版玩法策划案 V0.1

## 1. 项目概述

### 1.1 游戏定位

一款面向 Steam 平台的 **2D 都市女性人生模拟养成游戏**。

玩家扮演一名刚刚进入新人生阶段的年轻女性，在城市中拥有自己的住所，并通过工作、生活、社交、恋爱、消费、兴趣、副业、创业等行为，自由决定自己接下来的人生。

游戏不预设唯一的“成功人生”。

玩家可以成为职场精英，可以辞职创业，可以认真谈恋爱，也可以长期单身；可以努力赚钱买更好的房子，也可以降低工作强度，把时间花在兴趣、朋友和自己的生活上。

核心体验可以概括为：

> **白天面对生活，晚上经营自己。**

---

# 2. 核心设计目标

游戏希望给玩家提供三种主要体验。

### ① “我的人生是我自己选出来的”

玩家不是跟随一条固定剧情，而是在大量日常选择中逐渐形成自己的人生。

例如：

工作表现不错  
→ 获得晋升机会  
→ 接受晋升  
→ 收入增加但工作时间增加  
→ 房间越来越乱  
→ 社交时间减少  
→ 与某个角色关系疏远  
→ 玩家开始考虑换工作 / 辞职 / 继续卷

这里没有标准答案。

---

### ② “下班以后终于属于我自己”

白天的工作承担一定的现实压力，而真正高自由度的部分发生在玩家自己的时间里。

玩家下班之后可以：

约朋友、约会、逛街、买衣服、整理房间、装修、做饭、追剧、发展兴趣、做副业、健身、学习、参加活动，或者单纯什么都不干。

**“今晚干什么”应该成为游戏最频繁的小决策。**

---

### ③ “生活越来越有自己的样子”

游戏的重要反馈不只是数值增长。

玩家玩了 20 小时以后，应该可以明显看到：

**这个角色和这个家已经变成了“我的”。**

比如她穿什么衣服、做什么工作、家里摆什么、周末去哪里、和谁关系最好、有没有对象、有什么兴趣、收入多少、生活规律如何，都是玩家长期选择积累出来的结果。

---

# 3. 玩家画像

目前建议核心玩家定义为：

**18–35 岁女性为核心，同时覆盖喜欢 Cozy Game、Life Sim、恋爱、装修、换装和剧情游戏的泛用户。**

她们不一定喜欢传统数值养成，但通常会对以下内容敏感：

- 漂亮角色和服装
- 有代入感的都市生活
- 装修自己的空间
- 恋爱 / 人际关系
- 收集
- 轻量小游戏
- “做自己的选择”
- 情绪价值
- 日常细节
- 人生 IF 体验

因此这个项目不能只靠传统的：

> 体力 + 金钱 + 魅力 + 好感度

否则很容易变成换皮数值养成。

真正的竞争力应该来自**“我的生活真的因为我的选择发生变化”**。

---

# 4. 世界观与玩家身份

## 4.1 基础背景

现代架空都市。

不建议直接绑定上海、深圳、东京等现实城市，但整体生活方式可以明显参考东亚一线都市。

玩家来到这座城市，正式开始独立生活。

初始状态：

**一间普通出租屋 + 一份基础工作 + 少量存款 + 少量社会关系。**

从这里开始，人生完全交给玩家。

---

# 5. 开局系统

## 5.1 角色创建

基础内容：

姓名、外观、发型、肤色、初始服装等。

不建议把捏脸做得特别重，重点应该放在后续换装和人生发展。

---

## 5.2 心理测试

开局通过一组生活化问题完成轻量人格测试。

例如：

> 周五晚上，同事突然邀请你参加聚会，你通常会？

玩家连续完成若干题目后，形成初始人格倾向。

但这里有一个重要原则：

### 人格不是职业。

不要：

> 测出 INTJ → 自动程序员。

而是影响：

**初始属性 + 初始事件权重 + 部分对话选项 + NPC 初始互动 + 少量剧情入口。**

后续玩家行为仍然可以改变人物。

这样心理测试才是“我的故事起点”，而不是把玩家锁死。

---

# 6. 核心游戏循环

整个游戏建议建立三个尺度的循环。

## 6.1 每日循环

**起床 → 白天安排 → 工作/自由活动 → 下班 → 夜间自由活动 → 回家 → 状态结算 → 睡觉**

这是最基础的循环。

玩家每天拥有有限的：

**时间 / 精力 / 金钱**

所以不可能什么都做。

例如今天晚上只有两个行动时间：

> 去逛街  
> ↓  
> 买了一件裙子  
> ↓  
> 回家已经很晚  
> ↓  
> 没有收拾房间  
> ↓  
> 房间杂乱度继续增加

这就是非常轻的资源决策。

---

## 6.2 每周循环

周一到周五形成积累。

压力增加、工资推进、家务积累、NPC 发消息、出现活动邀请。

到了周末，玩家拥有更大的自由度。

例如：

**周六上午：**

整理房间 / 睡懒觉 / 约会 / 逛街 / 做副业 / 学习 / 出城

**周六晚上：**

朋友聚会 / 酒吧 / 在家看电影 / 恋爱事件 / 特殊活动

所以：

> **工作日制造生活状态，周末提供释放和改变。**

---

## 6.3 长期循环

长期则是：

**生活 → 积累资源与关系 → 获得新机会 → 做人生选择 → 解锁新的生活方式 → 继续生活**

最终玩家会逐渐形成完全不同的人生。

---

# 7. 核心系统

这里我建议暂时分成 **8 个系统**。

## 7.1 时间 / 日程系统

整个游戏的底层系统。

一天划分为若干时间段，例如：

上午 / 下午 / 傍晚 / 夜晚。

不建议真的按照分钟管理，否则容易变成日程管理器。

玩家安排活动消耗时间。

不同工作、职业和人生阶段会改变时间结构。

例如创业以后：

> 不再固定 9–6 上班。

玩家获得更多时间自由，但是：

> 收入不稳定 + 工作事件更加随机。

这样职业路线才真正改变玩法。

---

# 8. 职业系统

职业系统至少包含：

**打工 / 转职 / 副业 / 创业**

四种状态。

### 打工

选择公司与行业。

例如：

互联网、广告、设计、金融、游戏、媒体、消费品牌等。

公司内部存在：

同事、领导、客户、项目、办公室政治、绩效等事件。

但不做成重度职场模拟器。

主要通过**事件选择 + 少量小游戏**呈现。

例如：

> 同事把一个烂项目甩给你。

A. 接下来  
B. 当场拒绝  
C. 找领导沟通  
D. 和同事交换资源

不同选择影响：

关系 / 压力 / 职业评价 / 后续事件。

---

# 9. 生活状态系统

这是我认为目前最值得重点做的系统之一。

角色拥有：

**精力、压力、心情、生活秩序**

但尽量不要全部直接显示成 RPG 数值。

它们通过角色行为和环境表现出来。

例如连续加班：

> 衣服堆在椅子上  
> 外卖盒出现  
> 床没有整理  
> 植物缺水  
> 冰箱变空  
> 角色回家直接倒在床上

玩家实际上是**通过自己的房间看到自己的生活状态**。

这会比屏幕右上角显示：

> 压力 82/100

有表现力得多。

---

# 10. 房间 / 家居系统

房间既是玩家 Home Base，也是游戏非常重要的成长反馈。

最开始：

> 普通出租屋。

随着游戏推进：

租房 → 更好的公寓 → 自己喜欢的住所。

玩家可以购买：

床、沙发、桌子、灯具、植物、摆件、墙纸、地毯、收纳用品等。

不同物品除了视觉效果，还可以产生轻度功能。

例如：

咖啡机  
→ 早晨快速恢复少量精力。

浴缸  
→ 解锁泡澡活动。

游戏机  
→ 解锁游戏娱乐。

瑜伽垫  
→ 解锁居家运动。

所以：

**装修 = 视觉表达 + 新生活方式。**

---

# 11. 家务 / 解压小游戏

这个部分应该成为 Cozy 感的重要来源。

例如：

整理衣柜、拖地、洗衣服、整理桌面、做饭、浇花、收拾床铺。

这些小游戏不追求难度。

重点是：

**脏乱 → 操作 → 整洁**

形成强烈视觉反馈。

尤其适合周末。

玩家甚至可以打开音乐，然后慢慢整理自己的房间。

---

# 12. 时尚 / 换装系统

城市中存在不同风格店铺。

例如：

基础通勤、Vintage、甜酷、设计师品牌、运动、街头、轻奢。

服装除了外观，可以带有：

**风格标签。**

例如：

简约 / 成熟 / 可爱 / 个性 / 性感 / 运动。

NPC 对不同风格可能存在偏好，但绝对不能设计成：

> 穿男主喜欢的衣服 = +20 好感。

更好的设计是产生**不同反应和事件**。

玩家最终形成的是自己的穿衣风格。

---

# 13. 社交与恋爱系统

恋爱是重要内容，但**不是游戏最终目标**。

玩家完全可以不恋爱。

NPC 包括：

朋友、同事、邻居、兴趣伙伴、恋爱对象等。

玩家不是进入“攻略男主界面”，而是在正常生活中认识角色。

比如你原本写的：

> GAP / 邂逅模拟器

这个思路我建议保留。

不同生活路线自然遇到不同的人。

例如：

经常健身  
→ 认识 A。

经常去 Live House  
→ 认识 B。

进入创业路线  
→ 在创业活动认识 C。

换工作  
→ 遇到 D。

所以：

> **玩家选择怎样生活，也决定她会遇到怎样的人。**

这个逻辑非常适合你的项目。

---

# 14. 恋爱设计原则

恋爱关系不应该只有：

认识 → 好感度 → 约会 → 告白 → 结婚。

而应该允许：

暧昧、朋友、恋爱、分手、复合、保持单身、错过、长期伴侣等状态。

甚至应该允许：

> **这个人很好，但我们的人生方向不一样。**

比如玩家决定去另一座城市创业，对方不愿意离开。

这时候玩家真正做的是**人生选择**，恋爱只是其中的一部分。

这会让这个游戏明显区别于传统乙女游戏。

---

# 15. 兴趣与小游戏

游戏中可以不断扩展轻量小游戏。

但小游戏必须绑定生活行为。

例如：

做饭 → 简单 Cooking  
咖啡 → 拉花  
整理 → 收纳  
摄影 → 构图拍照  
陶艺 → 制作  
逛街 → 搭配  
健身 → 节奏玩法  
工作 → 特定职业小游戏

原则：

> **小游戏是生活的触感，不单独为了小游戏而小游戏。**

---

# 16. 人生事件系统

整个游戏需要一个巨大的 Event Pool。

可以分成：

**日常事件 / 工作事件 / 社交事件 / 情感事件 / 城市事件 / 特殊人生事件。**

例如：

下雨、工资到账、房东涨租、朋友失恋、同事离职、喜欢的店倒闭、公司裁员、收到猎头邀请、朋友结婚、偶遇旧同事、家里东西坏了、有人约你周末出去。

这些事情组合起来，才能产生真正的：

> **“过日子感”。**

---

# 17. AI 随机公司 / NPC

你草图里面提到的“AI 随机行业公司”可以做，但我不建议现在把“AI”作为玩家感知的卖点。

底层可以使用程序化生成。

例如生成：

**公司类型 + 企业文化 + 工作强度 + 薪资 + 同事结构 + 随机事件池**

形成不同公司。

于是：

> 高薪高压大厂

和：

> 钱少事少小公司

带来的生活体验完全不同。

后续转职才会真正有意义。

---

# 18. 人生路线

游戏不设计传统职业树式结局。

而是形成若干动态人生方向：

**职场型 / 创业型 / 创作者型 / 自由职业型 / 生活型 / 社交型……**

而且允许混合。

例如：

> 白天广告公司上班  
> 晚上经营自己的首饰品牌  
> 周末参加市集  
> ↓  
> 副业收入越来越高  
> ↓  
> 辞职  
> ↓  
> 开工作室  
> ↓  
> 认识新的合作伙伴  
> ↓  
> 搬到更大的房子

这本身就是一条由玩家行为产生的故事。

# 19. 游戏真正的内容结构

现在我认为整个项目最重要的一张图其实是：

**职业**
↓  
获得金钱 / 消耗时间 / 产生压力

↕  

**日常生活**
房间 / 消费 / 兴趣 / 家务 / 休息

↕  

**社交关系**
朋友 / 同事 / 恋爱

↕  

**机会**
转职 / 创业 / 新地点 / 新角色 / 新生活方式

↕  

**玩家选择**

然后重新进入下一阶段。

因此我们的核心不是做很多系统。

核心是：

> **让一个系统里的选择，能够在另一个系统里产生后果。**

这应该成为之后所有系统设计的验收原则。

### 一、新增内容正式并入

**1. 服装不只是外观，要进入事件系统。**

服装具有风格标签，并影响 NPC 第一印象、部分事件触发和事件解决方式。

比如同样第一次进入公司：

穿得比较正式 → 某同事认为玩家靠谱；  
穿得比较个性 → 另一个 NPC 对玩家产生兴趣；  
穿某类小众品牌 → 可能触发“你也喜欢这个牌子？”的额外对话。

但我不建议做成简单的“正确穿搭 +5 好感”。核心应该是：

> **穿什么 → 别人如何认识你 → 改变部分事件可能性。**

这样换装才真正属于人生模拟，而不只是 Dress-up。

---

**2. 男主/可攻略角色采用“非固定剧情顺序”。**

这个我非常赞成，而且应该升级成项目核心特色。

传统乙女游戏通常是：

**认识角色 → 固定事件 1 → 固定事件 2 → 固定事件 3 → 告白**

我们可以改成：

**玩家生活轨迹 → 遇见角色 → 不同状态下发生不同事件 → 形成属于本局的关系经历。**

所以同一个角色，玩家 A 可能：

> 旅游认识 → 后来城市偶遇 → 成为朋友 → 恋爱。

玩家 B：

> 工作认识 → 一开始互相不喜欢 → GAP 期间重新遇见 → 恋爱。

玩家 C：

> 一直只是朋友。

因此真正值得做的是一个**Relationship Event Pool + 条件触发系统**，而不是传统线性“男主路线”。

这也对应你写的：

> **男主给每个玩家带来的情感感受 / 剧情顺序不同。**

这个应该保留。

---

**3. GAP 期升级为一个正式的人生阶段。**

你现在补充之后，我觉得 GAP 不能只是“辞职以后的一段剧情”。

它应该成为一个非常重要的特殊状态：

> **工作期：金钱相对稳定、时间受限。**  
> **GAP 期：时间高度自由、金钱持续消耗、未来高度不确定。**

玩家每天可以自由安排：

旅行、报班、学习、见朋友、投简历、做副业、躺平、整理房间、约会、参加活动……

这段时间的核心矛盾就是：

**自由感 ↔ 财务压力 ↔ 求职焦虑。**

这个很好，因为它天然形成玩法张力。

---

**4. 求职不要只是菜单操作。**

你提出的“投递工作玩法”可以成为 GAP 期核心玩法之一。

基本流程可以设计成：

**发现岗位 → 判断是否投递 → 准备材料 → 投递 → 等待 → 收到面试 → 准备程度 → 面试 → Offer / 拒绝**

这里几个变量可以互相作用：

岗位匹配度、履历、准备充分度、公司偏好、面试状态。

尤其你说的：

> **焦虑值越高，面试准备越困难。**

这个逻辑很好。

但我会稍微调整：不能让高焦虑直接导致玩家“越来越失败 → 更焦虑 → 更失败”的死亡螺旋。

可以变成：

**焦虑高 → 准备效率下降 / 出现更多干扰 → 玩家需要通过朋友、运动、整理房间、旅行、休息等方式调节。**

这样其他生活玩法就会反过来服务求职。

---

**5. 焦虑达到阈值 → 触发回家事件。**

这个也保留，但不要完全做成惩罚。

比如焦虑达到一定程度：

> 妈妈打电话：“要不要回来住几天？”

玩家可以选择：

**回家 / 再撑一段时间 / 找朋友聊聊。**

如果回家，就进入一个短期的“家庭生活阶段”。

家庭阶段可以恢复经济压力和部分状态，但同时产生：

父母询问工作、亲戚比较、家庭关系、童年物品、兄弟姐妹等事件。

这样“回家”本身又成为一段人生内容。

---

### 二、开局家庭结构

你新增了：

> 哥哥 / 弟弟  
> 默认多子女家庭。

这个可以。

但我建议不要把家庭做成复杂模拟系统。第一版只需要：

**父母 + 一个兄弟 + 家庭关系状态 + 家庭事件池。**

它主要承担三个作用：

**情绪支持、现实压力、人生背景。**

### 三、三个初始好友

这个设定也很好。

开局：

**男性好友 ×1  
女性好友 ×2**

其中：

**女性好友 A：不可攻略**  
**女性好友 B：可攻略**  
**男性好友：可攻略**

这样玩家一开始就有一个稳定的小社交圈，不会出现“游戏刚开始整个世界只有玩家一个人”的问题。

而且我建议三个人的人生也在变化。

比如：

一个准备结婚；  
一个正在疯狂搞事业；  
一个突然辞职去旅行。

玩家不是唯一在“过人生”的人。

这点会非常影响世界的真实感。

---

### 四、攻略对象重新定义

你现在提出：

> 一男一女都可以攻略，另一名女性朋友不可攻略。

我建议进一步明确一个原则：

**“可攻略角色”不是一个单独分类。**

NPC 首先是一个完整的人，其次才存在“是否可能发展恋爱关系”。

所以 UI 里不要出现：

> ❤️ 男主好感度 67

而可以表现成：

**熟悉 → 亲近 → 暧昧 / 挚友 → 恋人**

甚至部分状态不明确告诉玩家。

这样你的项目会明显更偏 **Life Sim + Relationship Simulation**，而不是披着 Life Sim 外壳的乙女游戏。

### 五、旅行系统 + 偶遇

你提出的这个例子很适合作为我们以后设计“动态人生事件”的模板：

> GAP 期间决定旅行  
> ↓  
> 机场办理行李  
> ↓  
> 触发搬运行李小游戏  
> ↓  
> 遇到戴眼镜的陌生男性  
> ↓  
> 根据小游戏结果 / 玩家行为产生不同事件  
> ↓  
> 后续在其他场景重新遇到  
> ↓  
> 才逐渐意识到这是一个重要角色

这里最重要的不是“搬箱子小游戏”。

而是：

> **小游戏结果也可以进入叙事。**

例如玩家搬不动：

他主动帮忙。

玩家自己成功：

他只是看到玩家，之后可能在登机口发生另一件事。

玩家把行李弄倒：

两个人一起捡东西。

玩家根本没有参加这个小游戏：

这次相遇甚至不会发生。

这才是自由人生模拟应该追求的感觉：

**“我当时做了一件很普通的事情，后来才发现它改变了我的人生。”**

这个设计思想我建议直接写进项目 Design Pillar。

### 六、初始财富值：我建议修改你的方案

你写的是：

> 心理测试 → 初始财富值 ±？  
> 财富高，另一个数值就低。

这里我不建议直接这么干。

因为**家庭财富不是人格特征**。心理测试回答“我喜欢独处”，不应该导致“我家比较有钱”。

我们可以拆成两个东西：

**人格测试**决定：

社交倾向、冒险倾向、秩序倾向、事业倾向等软属性。

然后单独设计一个：

**「人生起点」**

例如开局几个生活问题决定：

初始存款、家庭支持、职业基础、社交资源。

并且使用一种轻量的**起点预算机制**：

> 钱多，但职业基础普通；  
> 工作能力强，但存款少；  
> 人脉多，但生活秩序差。

这样既有差异，也不会把心理学和财富强行绑在一起。

# 七、现在这个项目的核心已经发生了一点变化

上一版我把它定义成：

> **“下班以后如何把生活过成自己想要的样子。”**

现在看完这批补充，我觉得这个定义已经**偏窄了**。

因为现在最有意思的部分已经包含：

**上班 → 辞职 → GAP → 旅行 → 求职 → 创业 → 回家 → 恋爱 → 单身 → 转行……**

所以更准确的项目核心应该变成：

> ## **模拟一段“不确定的人生”。**

玩家不是在选择：

> 「事业线 / 男主 A 线 / 男主 B 线」

而是在做：

> **今天我要怎么过。**

大量微小选择不断累积，最后形成：

> **这一局属于我的人生故事。**

这应该成为整个项目最顶层的设计方向。

而你提到的**“参考吴昊喜欢冤家路线”**和**“李大仁”**这种参考，下一步可以进入具体角色设计，但我建议先把它们抽象成 Relationship Archetype，比如**长期陪伴型、欢喜冤家型、偶遇型、事业伙伴型**，再设计具体人物。这样以后不会变成直接照着某个影视角色写。

现在我认为这个项目最值得继续深挖的已经不是“再增加什么玩法”，而是一个非常核心的问题：**我们到底怎么让玩家真的产生“这是我自己活出来的一局”，而不是看起来选择很多、实际上还是几个固定剧情分支。**这个问题解决了，项目的差异化才真正成立。

我更希望我们做成：

> **工作、金钱、焦虑、朋友、恋爱、穿搭、旅行、家庭、GAP 等系统互相触发事件，最后自然拼成玩家这一局的人生。**

比如你刚才那个**机场眼镜男**就特别适合这种设计。

他不应该是：

> 第 10 天固定出现 → 搬行李剧情 → 好感 +10。

而应该是：

**玩家刚好处于 GAP + 选择旅行 + 去了某个目的地 + 某个时间到机场 → 才可能碰见他。**

甚至碰见以后，因为玩家当时的穿搭、性格、行李小游戏结果不同，第一次见面的感觉也不同。

所以你刚才说的：

> **“男主给每个玩家带来的情感感受 / 剧情顺序不同。”**

其实就是这个游戏非常重要的特色。

**不是让玩家“选剧情”，而是让玩家“过生活，然后剧情发生”。**

我上一条最后想说的就是这个。这个方向我觉得比单纯“自由度很高的养成游戏”更有辨识度。

## 用户
可以的 我觉得还有一个办法就是让玩家能玩多周目 每次游戏时长可能为1-2年（游戏内时间），比如说一周目是从26岁开始，玩完后触发结局在28岁，那玩家这个时候可以触发二周目，差不多是29-30岁了这个时候（就是又想辞职gap的意思），到了二周目创业线也会相应解锁（或者说解锁更多）

## 助手
对，这个方向我觉得**比“每局从26岁重新开始”更适合你的游戏**。而且它能解决一个很实际的问题：你想让玩家体验职场、GAP、恋爱、创业、旅行、家庭等很多内容，如果全部塞进一次 26–28 岁的人生里，会非常拥挤；拆成多个“人生阶段”之后反而自然。

但我会改一个概念：**不要把二周目理解成传统意义上的 NG+，更像“人生新章 / Chapter 2”。**

### 我建议这样设计

**第一章：26–28 岁｜第一次 GAP**

这是玩家第一次真正拥有重新选择人生的机会。

核心内容集中在：

工作、辞职、GAP、求职、旅行、朋友、恋爱、独居、换装、消费、兴趣。

这一阶段玩家可能经历：

> 26 岁工作 → 27 岁辞职 → GAP 半年 → 旅行 → 找到新工作 → 28 岁进入相对稳定状态

也可能：

> 一直没辞职 → 晋升 → 恋爱 → 搬家 → 28 岁继续职场

甚至：

> 辞职 → GAP → 没找到合适工作 → 回家 → 再回城市。

然后 28 岁左右触发一个**阶段结局**。

注意，我建议叫“阶段结局”，不要真把人生 Ending 掉。

例如：

> **「好像终于稳定下来了。」**  
> 28岁，你有了一份还不错的工作，也搬进了新的房子。  
> 日子似乎开始走上正轨。

然后 Credits / 人生回顾。

---

过场之后：

# 第二章：29–31 岁｜第二次人生选择

时间过去一两年。

某一天玩家又坐在办公室里。

可能突然出现一句：

> **“我真的要一直这样下去吗？”**

然后进入第二阶段。

这时候游戏世界不是重置，而是**继承上一阶段的人生**。

你的：

房子、衣服、存款、朋友、恋爱关系、职业经历、性格变化、家庭关系、认识过的人……

原则上都还存在。

但是**人生问题变了。**

第一章玩家纠结的可能是：

> “我要找什么工作？”

第二章开始变成：

> “我要不要自己做点东西？”

所以你说的创业线在这个阶段大幅解锁，非常合理。

---

### 这样我们甚至可以把整个游戏做成三个年龄阶段

| 人生阶段 | 年龄 | 核心命题 | 主要新增内容 |
|---|---:|---|---|
| Chapter 1 | 26–28 | **我想过什么生活？** | GAP、求职、旅行、独居、恋爱 |
| Chapter 2 | 29–31 | **我要不要换一种活法？** | 创业、副业、长期关系、职业跃迁、住房升级 |
| Chapter 3 | 32–34 | **什么东西值得我长期留下？** | 事业稳定/转型、长期伴侣、家庭、生活方式选择 |

这里有个很重要的点：

**年龄增长不是简单增加新功能，而是改变同一件事情对玩家的意义。**

比如同样是“辞职”。

26 岁：

> “反正年轻，我想出去看看。”

30 岁：

> “我已经做到这个位置了，现在放弃值得吗？”

33 岁：

> “如果现在重新开始，我愿意承担这个成本吗？”

同样一个按钮，情绪完全不同。

这就开始有你这个游戏自己的东西了。

---

## 而且我建议：每章不要把所有内容都玩完

这特别重要。

假设 Chapter 1 有：

**120 个普通事件 + 30 个特殊事件 + 8 个旅行事件链 + 6 个主要关系角色。**

玩家一局可能只看到其中 40%。

比如一周目：

> GAP → 旅游 → 眼镜男 → 新工作。

另一个玩家：

> GAP → 报班 → 认识同学 → 创意副业 → 和女性好友发展恋爱。

甚至**同一个玩家重新从26岁开始**，也能体验另一种人生。

所以这里其实可以同时存在两种“重玩”：

### A. 继续人生

**26–28 → 29–31 → 32–34**

保留人生历史继续向前。

### B. 重开人生

重新回到 26 岁。

但是玩家已经解锁了一些新的：

**职业 / 地点 / 事件 / NPC / 初始条件 / 隐藏选择。**

这才是真正意义上的“二周目”。

所以我甚至建议我们以后策划案里把两个概念分开：

> **人生章节（Life Chapter）**：同一个角色继续长大。  
> **人生周目（New Life）**：重新从26岁开始另一种人生。

这样不会混乱。

---

## 创业线也可以因此设计得很好

我不建议“第一章禁止创业，第二章才开放”。

太游戏化了。

更自然的是：

**26岁也能创业，但条件苛刻、资源少、风险高、内容浅。**

比如第一章：

> 摆摊  
> 自媒体  
> 网店  
> 小工作室  
> 接自由职业单

这些其实就是创业种子。

到了第二人生阶段，如果玩家上一阶段积累了：

**资金 + 行业经验 + 人脉 + 副业经验**

就可能出现：

> 辞职全职做品牌  
> 找朋友合伙  
> 开工作室  
> 融资  
> 招第一个员工

创业系统自然扩张。

甚至一个玩家第一章根本没碰创业，第二章因为被裁员才第一次开始创业。

另一个玩家第一章已经偷偷做了两年副业，29 岁一开局就可以直接辞职。

**这两个人进入 Chapter 2 的体验完全不同。**

---

## 这样一来，“结局”也得重新定义

你的游戏我反而不建议做：

> BAD END  
> NORMAL END  
> TRUE END

因为和这个项目的价值观不搭。

我们做：

### 「这一阶段的你」

系统根据过去两年的行为生成一个阶段总结。

比如：

**28岁 ·「在路上」**

> 这一年你离开了原来的公司。  
> 去了3座城市。  
> 换过2份工作。  
> 认识了17个人。  
> 和××成为了很好的朋友。  
> 存款比两年前少了很多。  
> 但你第一次开始期待星期一。

然后展示玩家：

**26岁房间 → 28岁房间**

**26岁穿搭 → 28岁穿搭**

**26岁关系网 → 28岁关系网**

**职业轨迹**

甚至可以生成一张非常漂亮的：

> **MY LIFE · AGE 26–28**

人生记录卡。

这个东西对 Steam 玩家截图分享也会很有价值。

---

而且这么一改以后，我觉得我们这个项目的结构一下清楚很多：

> **一天是玩法循环。**  
> **一周是生活循环。**  
> **1–2年是一个人生章节。**  
> **多个章节组成一次完整人生。**  
> **重新回到26岁，则开启另一种人生。**

这套时间结构我建议直接定下来。后面我们设计职业、恋爱、GAP、创业甚至 NPC，都可以围绕这个时间尺度来做，不容易继续无限发散。

## 用户
对 可以的

## 助手
那这套我先视为当前项目的**核心时间结构**：

**日 → 周 → 1–2 年人生章节 → 多章节连续人生 → 重开人生周目。**

接下来继续做策划时，我会特别守住三个原则：每个人生章节有不同的核心命题；上一章节的职业、财富、关系、住房、性格与经历会影响下一章节；新章节以“扩大可能性”为主，而不是粗暴锁功能，例如创业在 26 岁可以萌芽，到 29–31 岁才真正形成完整玩法。

这样我们后面讨论任何新 Idea，都可以先判断它属于哪个年龄阶段、进入哪个循环、会影响哪些后续内容，避免最后变成一堆互不关联的系统。

## 用户
26-32岁？我没想好

## 助手
我觉得**26–32 岁是一个很顺的主区间**，而且比之前我随口提的 26–34 更收敛，适合你现在这个项目。

原因很简单：你想讲的核心内容——**初入稳定职场、第一次明显的职业倦怠、GAP、重新求职、关系变化、副业/创业萌芽、生活方式重构**——基本都能自然放进 26–32 这 6 年里。再往后做到 35+，就会越来越不可避免地碰到婚育、照护父母、住房资产、长期伴侣等更重的人生议题，项目体量会一下变大。

我建议先按 **3 个章节，每章约 2 年**：

| 章节 | 年龄 | 核心状态 | 主要内容 |
|---|---:|---|---|
| Chapter 1 | 26–28 | 第一次重新选择 | 职场、辞职、GAP、求职、旅行、恋爱、独居 |
| Chapter 2 | 28–30 | 开始建立自己的生活 | 转行、副业、创业萌芽、关系深化、住房升级 |
| Chapter 3 | 30–32 | 决定什么值得长期投入 | 创业扩张/职业稳定、长期关系、朋友变化、生活方式定型 |

我甚至觉得 **32 岁作为第一部游戏的终点很好**。

因为它不是“人生结束”，而是：

> **玩家从 26 岁那个还在摸索的人，走到了 32 岁一个已经形成自己生活方式的人。**

最后可以给一个阶段性 Ending，然后告诉玩家：

**“32 岁之后，她的人生还会继续。”**

这比硬做到 40 岁更有余味，也方便以后真想扩 DLC 或续作。

不过年龄最好不要绑得特别机械，比如“每一章必须刚好两年”。更合理的是内部按章节推进，玩家看到的是：

**26岁春 → 27岁 → 28岁秋……**

某些阶段可以快进几个月。因为如果真的把 6 年 × 365 天全部按日循环做出来，玩家会玩到麻木。

所以我目前会定成：

> **故事跨度：26–32 岁。**  
> **实际重点体验：每个人生阶段中的关键数月。**  
> **无意义的稳定时期可以时间跳跃。**

这样既有“六年人生”的重量，又不会做成 2190 个游戏日。

还有一个选择我建议你之后考虑：**开局到底固定 26 岁，还是允许 25/26/27 三选一。**我目前偏固定 26 岁，因为固定年龄更方便我们精准写事件和角色关系。

## 助手
可以，**5 个可攻略角色：3 男 + 2 女**，我觉得对你这个体量反而比较合适。再多的话，每个人的事件池很容易变薄。

但我建议这五个人不要设计成传统乙游的“五条角色线”，而是设计成 **5 种不同的亲密关系体验 + 5 种不同的人生交集方式**。这样才能服务我们前面定的“玩家是在过生活，关系是在生活中发生”。

我先给他们占五个“生态位”，具体人设后面再慢慢磨：

| 角色 | 性别 | 初始关系 | 情感体验 | 与玩家人生的交集 |
|---|---|---|---|---|
| A | 男 | 多年好友 | **李大仁型：陪伴→后知后觉** | 从26岁开始就在身边，贯穿多个阶段 |
| B | 男 | 陌生人 | **偶遇型：陌生→反复相遇→吸引** | GAP / 旅行 / 城市随机事件中认识 |
| C | 男 | 职场关系 | **冤家型：冲突→理解→暧昧** | 工作、跳槽、创业等事业内容 |
| D | 女 | 原有好友 | **朋友→边界模糊→确认感情** | 原本就是生活圈成员，关系变化非常生活化 |
| E | 女 | 后期认识 | **新鲜感/共同成长型** | 兴趣、课程、副业、创业或新生活圈认识 |

这里最重要的是**不要让五个人只是性格不同**。

如果只是：

高冷男 / 温柔男 / 毒舌男 / 御姐 / 甜妹

还是传统攻略游戏。

我要让他们连**进入玩家人生的方式都不同**。

### 比如 A「多年好友」

他最大的特点甚至可以是——**太容易见到了。**

玩家26岁开局就认识他。

一起吃饭、吐槽工作、帮忙搬家、失恋找他、GAP的时候一起出去……

玩家甚至可能前两个游戏年完全没觉得这是攻略对象。

到了29岁左右，关系才有机会发生变化。

但如果玩家一直没有往那个方向发展：

这一下就有意思了。

### B「偶遇男」

就是你之前画的机场搬箱子那个方向。

第一次见面甚至没有名字。

旅行遇见一次。

几个月后可能在城市某个地方再次遇见。

玩家：

> “怎么又是你？”

第三次见面才真正交换联系方式。

所以他的体验核心就是：

**缘分感。**

而且不同玩家第一次认识他的地方可以不同。

有人机场认识。

有人咖啡店认识。

有人朋友聚会认识。

这就特别符合你之前说的：

> **同一个角色，每个玩家感受到的剧情顺序可以不同。**

---

### C「职场冤家」

这个角色就应该和玩家的**事业选择高度绑定**。

关系一下发生变化。

于是他的感情线实际上也是：

**26岁的我怎么看你 → 30岁的我重新怎么看你。**

这个就很适合你这个跨年龄人生结构。

D 和 E应该有自己的关系逻辑。

例如 D 是多年女性好友。

最开始两个人可能：

逛街、睡对方家、旅行、互相吐槽对象……

玩家甚至会经历：

这和男性青梅竹马的体验其实可以完全不同。

**这次我要辞职。  
这次我要去旅行。  
这次我要参加那个课程。**

这时候“多周目”就不是为了刷不同结局，而是真的：

> **再过一次完全不同的人生。**

# 独游｜当前项目大纲 V0.1

## 01. 项目定位

### 基础定位

- **平台：Steam**
- **表现：2D**
- 不做 3D
- 不做像素风
- 偏女性向
- 都市生活题材
- 高自由度人生养成 / Life Sim
- 包含恋爱，但**恋爱不是唯一目标**
- 玩家可以完全不恋爱

### 当前核心体验

目前最重要的一句话可以概括为：

> **玩家不是选择一条固定剧情线，而是在过自己的生活，然后剧情自然发生。**

玩家通过工作、辞职、GAP、求职、恋爱、朋友、旅行、消费、穿搭、居住、家庭、副业、创业等选择，逐渐形成属于这一局的人生。

重点不是“攻略所有内容”，而是：

> **这一局是我自己活出来的。**

---

# 02. 游戏时间结构

目前基本形成：

**日 → 周 → 人生章节 → 连续人生 → 多周目**

### 日

最基础的 Gameplay 单位。

围绕：

> 工作 / 自由活动 / 社交 / 生活 / 休息

展开。

具体“一天分几个时间段、一天能行动几次”**尚未确定**。

### 周

工作日与周末形成不同节奏。

例如：

**工作日**

工作 → 时间减少 → 压力/疲劳积累 → 家务积累 → 下班安排有限

**周末**

拥有更多自由时间，可以整理房间、约会、逛街、发展兴趣、旅行、做副业等。

### 人生章节

目前倾向：

> **每个阶段覆盖约 1–2 个游戏内年份。**

例如最初讨论的是：

**26岁 → 28岁**

之后进入下一人生阶段。

### 总年龄跨度

目前考虑：

> **约 26–32 岁**

但**还没有最终锁死**。

也还没有确定一定要：

26–28 / 28–30 / 30–32

这样严格切三段。

### 连续人生

进入下一人生阶段后，不清空上一阶段结果。

继承：

- 职业经历
- 财富
- 住房
- 人际关系
- 恋爱状态
- 玩家经历
- 部分性格/生活状态

随着年龄和经历变化，新的生活可能性逐渐增加。

例如创业相关内容可以在后续人生阶段进一步展开。

### 真正的多周目

除了“继续长大”，还允许玩家：

> **重新回到较早年龄，再过一次不同的人生。**

第一次可能：

> 工作 → 辞职 → GAP → 旅行 → 恋爱 → 再就业

下一次可能：

> 工作 → 晋升 → 副业 → 创业 → 单身

多周目的意义不是单纯刷 Ending，而是体验：

> **“如果当时我做了另一个选择呢？”**

---

# 03. 人生路线

目前不是设计固定的：

> 职场线 / 恋爱线 / 创业线

而是由玩家行为逐渐形成路线。

已经涉及：

### 工作

包括：

- 上班
- 公司
- 同事
- 职场事件
- 职业发展
- 跳槽
- 辞职

公司/行业可以具有一定程序化差异。

---

### GAP

GAP 是一个**正式人生状态**，不是几段辞职剧情。

工作状态偏：

> **收入稳定 + 时间有限**

GAP 状态偏：

> **时间自由 + 存款持续消耗 + 对未来的不确定**

GAP 期间可以：

旅行、报班、学习、见朋友、投简历、做副业、休息、整理房间、约会、参加活动等。

---

### 求职

目前考虑形成实际玩法，而不是“点击找工作”。

大致涉及：

**发现岗位 → 投递 → 准备 → 等待 → 面试 → Offer / 拒绝**

其中玩家自身状态可能影响求职。

例如：

> 焦虑较高 → 面试准备更加困难。

但已经明确要避免：

> 焦虑 → 面试失败 → 更焦虑 → 更容易失败

这种不可恢复的负反馈死循环。

---

### 副业 / 创业

已经确定属于人生可能性之一。

尤其后续人生阶段：

> **创业相关内容会增加或深化。**

但目前还没有确定创业具体怎么玩。

---

# 04. 生活系统

## 房间 / 居住

房间是玩家重要的生活空间。

不是纯装修展示。

玩家工作和生活状态可以直接反映在房间里。

例如：

连续加班  
→ 没时间整理  
→ 衣服堆积  
→ 外卖盒增加  
→ 房间逐渐变乱。

---

## 家务 / 解压小游戏

已经有明确 Idea：

> **周末整理房间成为一种放松玩法。**

例如：

整理、清洁、收纳等。

重点是形成：

> **混乱 → 玩家操作 → 整洁**

的视觉和情绪反馈。

其他放松小游戏可以继续存在，但目前还没有具体锁定。

---

# 05. 换装 / 时尚

换装不是单纯 Cosmetic。

服装可以具有：

> **风格标签**

并可能影响：

- NPC 第一印象
- 对话
- 部分事件触发
- 部分事件处理方式

但已经明确：

**不希望做成“穿对衣服 = 好感 +10”。**

也就是说，穿搭属于玩家身份表达，同时会对世界产生一定反馈。

---

# 06. 社交与关系系统

关系系统是目前已经出现较明显差异化的部分。

不采用单纯：

> 陌生 → 好感度 → 恋爱 → 结婚

的线性结构。

目前已经考虑存在：

- 陌生
- 认识
- 朋友
- 亲密朋友
- 暧昧
- 恋人
- 分手
- 复合
- 长期伴侣
- 单身
- 419 / 一夜情
- 炮友

具体状态机**尚未正式确定**。

---

# 07. 可攻略角色

### 当前确定

**4 名男性可攻略角色。**

此前讨论过女性可攻略角色，目前存在“两名女性可攻略”的方向，但最终人数和具体角色仍由你后续决定。

### 核心规则

人物人设、职业、性格、背景、具体感情体验：

> **由你作为主策决定，目前不继续预设。**

### 关系体验原则

同一个角色不一定拥有完全固定的剧情顺序。

例如玩家可能：

> 旅行时第一次遇见某人

另一局则可能：

> 在城市活动中先认识他，旅行事件后来才发生。

因此：

**玩家的生活轨迹会影响相遇时间、相遇方式和关系发展顺序。**

甚至部分角色可以在某一周目完全错过。

---

# 08. 419 / 炮友等成人关系

目前已经确认希望纳入这种关系可能性。

但两者需要区分：

### 419

偏一次性事件/关系。

### 炮友

属于可以持续存在的关系状态。

并且：

> **发生性关系 ≠ 自动增加好感度。**

之后可能：

继续约、停止联系、尴尬、成为朋友、进入暧昧、发展恋爱等。

目前仍需要以后明确：

- 炮友能否转恋爱
- 恋爱能否转回非恋爱亲密关系
- 能否同时维持多个关系
- 其他 NPC 是否知情
- NPC 如何看待非排他关系
- 不同关系之间如何冲突

成人关系事件需要明确双方同意和边界。

---

# 09. 家庭

目前考虑玩家来自：

> **多子女家庭**

存在：

- 父母
- 兄弟

家庭不是背景板。

例如玩家 GAP / 焦虑达到一定状态后，可以出现：

> **回家住一段时间**

这样的生活变化。

家庭可能同时承担：

**支持 + 压力 + 人际关系 + 人生事件**

但目前还没有展开具体家庭玩法。

---

# 10. 朋友

玩家开局不是完全孤立状态。

目前讨论过：

> **1 名男性朋友 + 2 名女性朋友**

其中部分朋友可能具有恋爱发展可能。

但具体角色结构仍然没有最终锁死。

比较明确的一点是：

> **朋友自己也应该在过人生。**

NPC 不应该永远站在原地等玩家触发剧情。

---

# 11. 事件系统

这是整个项目非常核心的一层。

事件来源可能包括：

**工作、家庭、朋友、恋爱、城市、旅行、GAP、求职、穿搭、玩家状态等。**

事件不是完全按照固定剧情顺序播放。

更理想的逻辑是：

> **玩家状态 + 当前人生阶段 + 地点 + 关系 + 历史行为 → 满足条件 → 事件出现**

例如之前讨论过的机场偶遇：

GAP  
→ 玩家决定旅行  
→ 到机场  
→ 发生行李相关小游戏  
→ 某角色出现  
→ 玩家行为影响第一次互动  
→ 以后可能再次相遇。

这种普通生活行为最终形成重要人生节点，是目前比较符合项目方向的事件类型。

---

# 12. 玩家状态

目前已经隐约出现：

- 金钱
- 时间
- 精力/疲劳
- 压力
- 焦虑
- 房间状态
- 职业状态
- 人际关系
- 玩家人格/倾向

但这一层**还没有正式定案**。

尤其需要解决：

> 压力和焦虑是不是两个值？  
> 是否需要心情？  
> 哪些数值玩家可见？  
> 哪些只作为后台状态？  
> 数值之间如何互相作用？

这是目前比较明显的空缺。

---

# 13. 开局

目前存在心理测试 Idea。

心理测试可能影响：

- 初始人格倾向
- 部分事件概率
- 对话
- 初始状态

但已经指出一个逻辑问题：

> **心理测试不应该直接决定家庭财富。**

人格与经济出身属于不同维度。

因此“初始财富 / 家庭条件怎么产生”目前**仍未确定**。

---

# 14. 阶段结局与人生回顾

每个 1–2 年阶段结束后，可以出现：

> **阶段性人生结算**

但不是传统意义上的：

**Good End / Bad End / True End**

因为这个项目没有唯一正确人生。

阶段结局更接近：

> **“这两年，你过成了什么样？”**

然后继续进入下一人生阶段，或者开启新的周目。

具体结算形式目前没有最终确定。

---

# 15. 当前整个游戏的逻辑骨架

现在已经能压缩成：

> **玩家拥有有限的时间、金钱和个人状态**
>
> ↓
>
> **每天选择工作、生活、社交、恋爱、休息、兴趣等行为**
>
> ↓
>
> **行为改变职业、财富、关系、生活状态**
>
> ↓
>
> **不同状态触发不同人生事件**
>
> ↓
>
> **事件进一步产生机会和选择**
>
> ↓
>
> **长期积累形成玩家自己的职业、关系与生活轨迹**
>
> ↓
>
> **经过 1–2 年形成一个人生阶段**
>
> ↓
>
> **继承结果进入下一年龄阶段 / 重开另一周目**

目前真正的核心其实已经比较清楚：

## 当前整体流程

目前比较清晰的一条主流程是：

**26岁左右开局 → 建立初始状态 → 正常工作生活 → 累积压力/金钱/关系变化 → 出现人生事件 → 玩家选择继续工作、辞职、GAP、跳槽、副业等 → GAP阶段自由安排生活 → 求职/旅行/社交/恋爱/休息 → 重新进入新的工作或生活状态 → 进入下一年龄阶段 → 解锁更深的职业/创业/关系内容 → 形成阶段结局 → 继续人生或重开新周目**

> **每天安排生活 → 状态发生变化 → 触发事件 → 做选择 → 改变后续人生 → 继续下一天。**

所以它不是传统固定剧情推进，而是玩家通过日常选择不断把人生“推”向不同状态。

## 每日/每周流程

**起床 → 上班/日间活动 → 下班 → 自由安排 → 回家 → 处理生活状态 → 睡觉 → 下一天**

周末则拥有更大的自由度，可以做更完整的生活活动，比如：

旅行、报班、收拾房间、逛街、约会、参加活动、做副业、彻底休息。

这里形成一个比较明确的节奏：

> **工作日制造压力和生活积累，周末让玩家处理、释放和改变生活。**

## GAP阶段流程

GAP是目前比较重要的一段特殊状态。

进入方式可能来自辞职、被裁、主动休息等。

进入后，生活结构会从：

**稳定收入 + 时间紧张**

切换成：

**时间自由 + 存款消耗 + 未来不确定**

玩家可以自由安排：

旅行、学习、报班、投简历、准备面试、见朋友、恋爱、副业、躺平、回家、整理房间等。

同时还会存在焦虑、求职压力、经济压力之类的状态变化。

最终可能走向：

**重新就业 / 转行 / 继续GAP / 副业转主业 / 创业 / 回家调整**

## 下一人生阶段

大概到了28、29、30岁以后，玩家不会重置。

会继承：

职业经历、存款、住房、朋友、恋爱关系、认识过的人、部分性格与经历。

然后新的问题开始出现，比如：

之前只是副业 → 后来可以真正创业。

之前只是约会 → 后来可能进入长期关系、分手、复合或保持单身。

之前只是租房 → 后来可能升级住房和生活方式。

所以玩法不是“通关后归零”，而是人生阶段不断叠加。

# 当前主要玩法

目前可以归成下面几个核心模块。

| 玩法模块 | 当前核心内容 |
|---|---|
| **时间/日程玩法** | 每天有限时间，安排工作、生活、社交、休息等行为 |
| **职场玩法** | 上班、同事、领导、项目、晋升、跳槽、辞职、公司事件 |
| **GAP玩法** | 高自由时间安排、存款消耗、焦虑、旅行、学习、重新找方向 |
| **求职玩法** | 找岗位、投递、准备、面试、Offer/拒绝 |
| **副业/创业** | 前期可作为副业萌芽，后期年龄阶段进一步展开创业 |
| **关系玩法** | 朋友、暧昧、恋爱、分手、复合、长期关系、单身等 |
| **成人关系玩法** | 419、炮友等非传统亲密关系状态，与恋爱并列而非单纯好感升级 |
| **换装玩法** | 穿搭、风格标签，并可能影响NPC第一印象和事件 |
| **房间/装修** | 居住空间不断变化，反映玩家生活状态和人生阶段 |
| **家务/解压小游戏** | 清洁、整理、收纳等，从混乱到整洁形成解压反馈 |
| **旅行玩法** | 尤其在GAP阶段，可以进入新地点并触发事件、关系和偶遇 |
| **家庭玩法** | 父母、兄弟、回家、家庭支持和压力 |
| **朋友系统** | 初始已有社交圈，NPC自己也会发生人生变化 |
| **事件系统** | 根据年龄、状态、地点、关系、历史行为动态触发事件 |
| **多周目玩法** | 重新从较早年龄开始，走另一条人生，不只是刷不同结局 |

其中真正的核心不是这些玩法单独存在，而是它们互相影响。

比如：

**工作太忙 → 房间变乱 → 压力升高 → 周末选择整理而不是约会 → 某段关系进展变慢。**

或者：

**辞职 → GAP → 去旅行 → 认识某人 → 回城市后再次遇见 → 影响后续关系。**

又或者：

**长期做副业 → 积累经验和人脉 → 到29、30岁时创业选项更成熟。**

这类“跨系统后果”才是你这个项目真正应该抓住的东西。

目前最缺的还是三个底层规则：**一天具体怎么操作、时间怎么跳、玩家状态到底有哪些。**这三个一旦定下来，上面这些玩法才算真正开始成立。
